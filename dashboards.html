RarezWarez AI Inventory Pipeline

Serverless Data Engineering & Applied AI

Google Cloud Run Python Gemini AI Databricks Streamlit Power BI

Project Overview

An end-to-end e-commerce data pipeline that turns raw, unsorted product photography into ready-to-list eBay inventory — no manual data entry involved. Photos are batched, segmented, and sent through a serverless AI service that writes the SEO title, condition, description, and pricing for every item automatically.

Behind the Pipeline

Photos sync to a Google Cloud Storage bucket and are picked up every minute by a Python service running on Google Cloud Run. Items are separated automatically by detecting a "blackout" divider photo — the lens covered by hand between items — using image-brightness detection. Each item's photos are sent to the Gemini API, which returns a structured listing (title, condition, description, and estimated value/shipping) as clean JSON. The finished listings are then loaded into a Databricks SQL warehouse, managed day-to-day through a custom Streamlit terminal, and tracked in Power BI to compare AI-estimated pricing against what items actually sell for.

Key Highlights

  • Physical Segmentation, No Manual Sorting: A single blackout photo — lens covered by hand — is enough to split a 200+ photo batch into individual items, with no folder organizing or manual tagging required.
  • AI-Generated Listings: The Gemini API reads each item's photos and produces a ready-to-post eBay listing (title, condition, description, pricing) in one structured pass.
  • Closed-Loop Analytics: Power BI compares the AI's estimated value against the actual sold price, turning every completed sale into feedback on how well the model is pricing inventory.

CFPB Consumer Complaint Analysis

Interactive Power BI Dashboard

Databricks API Power BI Automated Refresh

Project Overview

This dashboard provides a comprehensive visual analysis of over 8.3 million consumer complaints filed with the Consumer Financial Protection Bureau (CFPB) between January 2025 and July 2026. By structuring and visualizing this massive dataset, the report identifies systemic issues, geographic pain points, and company-specific trends within the financial sector.

Behind the Dashboard

This isn't a one-time export — the report is wired directly into a live data pipeline. New complaint data is pulled from a Databricks workspace via a scheduled API call, then automatically transformed and loaded into the reporting layer. That means the numbers above refresh on their own, with no manual downloads or file handling required to keep the dashboard current.

Key Insights Discovered

  • Credit Bureaus Dominate the Data: The vast majority of consumer grievances are directed at the "Big Three" credit reporting agencies. TransUnion, Equifax, and Experian account for over 7.1 million of the total complaints analyzed.
  • Root Cause Identification: Utilizing decomposition tree analysis, the data reveals that "Credit reporting" is the primary product of concern. Drilling down further, "Incorrect information" acts as the leading sub-issue, driving over 4.3 million specific complaints.
  • Volume Trends & Geography: The 3-month rolling average highlights a steady, continuous upward trend in complaint volume from early 2025 through mid-2026. Additionally, geospatial tracking maps out regional densities of delayed company responses (taking over 3 days).

Contact Center Service-Level Agreement

Interactive Power BI Dashboard

Python Local Database Local ELT Pipeline Power BI

Project Overview

This dashboard tracks Service-Level Agreement (SLA) performance across a contact center's 52,000+ customer calls in 2021. It gives leadership a clear, day-by-day view of how consistently the team is meeting its response and handling targets, and points to where call length is putting that performance at risk.

Behind the Dashboard

Unlike the CFPB report above, which pulls automatically from a cloud data platform, this pipeline runs entirely locally, end to end. Raw call records are extracted, cleaned, and loaded using a custom Python-built ELT process into a local database, then modeled and published into Power BI. Without a managed cloud platform doing the heavy lifting, this required hands-on engineering at every stage: scripting the extraction and transformation logic, managing the local database, and scheduling the refresh process — the kind of ground-up pipeline work that goes into building reliable reporting from scratch.

Key Insights Discovered

  • SLA Performance is Strong, but There's a Gap: 92% of all calls met the Service-Level Agreement target in 2021. The remaining 8% — roughly 4,100 calls — represents missed commitments worth tracking closely, since each one is a customer who didn't get the response they were promised.
  • Wait Times Aren't the Bottleneck — Handling Time Is: Customers wait only 17 seconds on average before reaching an agent, but the call itself takes nearly 5 minutes to resolve. Since handling time makes up almost the entire length of a call, it's the biggest opportunity for improving both efficiency and customer experience.
  • Longer Calls Drive SLA Misses: Days with longer average handle times consistently show lower SLA compliance, with some dropping into the 80% range once handling time crosses roughly 5 minutes. This points to a clear opportunity: shortening time spent per call, through agent coaching, better tools, or streamlined processes, is likely the fastest way to lift SLA performance above the current 92% baseline.
